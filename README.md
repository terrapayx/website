# Terra Pay X Website

Public-facing website for Terra Pay X — cloud-native payments infrastructure and Terra Pay X Labs advisory services.

Built with Next.js 14 (static export), Tailwind CSS, deployed to S3 + CloudFront.

## Development

```bash
npm install
npm run dev      # localhost:3000
npm run build    # production static export → /out
```

## Governance

This repository is enrolled in the Terra Pay X AI Governance Review system. All pull requests trigger an automated governance review via the AI control plane.

Risk classification for this repository (L1–L6) is documented in `.github/pull_request_template.md`.
